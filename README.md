# 💈 Barbearia 

Site institucional desenvolvido para a **Barbearia do Yago**, com foco em apresentar os serviços, facilitar o contato com clientes e fortalecer a presença digital da barbearia.

## 📌 Sobre o projeto

O projeto foi criado com o objetivo de desenvolver uma presença online moderna e profissional para a Barbearia do Yago.

A proposta é permitir que novos clientes conheçam a barbearia, visualizem os serviços disponíveis e encontrem rapidamente as informações necessárias para entrar em contato e realizar um agendamento.

## ✨ Funcionalidades

* 🏠 Página inicial moderna e responsiva
* 💈 Apresentação da barbearia
* ✂️ Exibição dos principais serviços
* 💰 Área para preços dos serviços
* 📱 Design adaptado para celulares, tablets e computadores
* 📍 Localização da barbearia
* 📲 Botão de contato/agendamento pelo WhatsApp
* 📸 Galeria de trabalhos
* ⭐ Área para avaliações de clientes
* 🔗 Links para redes sociais

## 🎨 Design

O visual foi desenvolvido pensando no estilo tradicional e moderno de uma barbearia, utilizando uma interface elegante e objetiva.

A navegação foi planejada para que o cliente consiga encontrar rapidamente:

**Serviços → Preços → Trabalhos → Localização → Agendamento**

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📱 Responsividade

O site foi desenvolvido seguindo o conceito **Mobile First**, garantindo uma boa experiência em diferentes tamanhos de tela.

Compatível com:

* 📱 Smartphones
* 📲 Tablets
* 💻 Notebooks
* 🖥️ Desktops


## 🎯 Objetivo

Este projeto busca demonstrar como uma presença digital bem estruturada pode ajudar um comércio local a:

* Atrair novos clientes
* Facilitar agendamentos
* Divulgar seus serviços
* Apresentar seus trabalhos
* Fortalecer sua marca na internet
